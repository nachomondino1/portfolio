Recetas Recipes

Catálogo de recetas familiares (30 y sumando) que antes vivían en un Google Doc: cards con foto, tiempo y dificultad, filtrables por categoría y ordenables por tiempo, para encontrar qué cocinar de un vistazo en vez de scrollear un documento de texto. A catalog of family recipes (30 and counting) that used to live in a Google Doc: cards with photo, time and difficulty, filterable by category and sortable by time, to find what to cook at a glance instead of scrolling a text document.

Stack Python, JavaScript vanilla (SPA con hash routing), HTML/CSS, Google Docs (vía conector de Claude Code), pytest, Claude Code Python, vanilla JavaScript (hash-routed SPA), HTML/CSS, Google Docs (via Claude Code connector), pytest, Claude Code

ResultadosResults
  • El Google Doc sigue siendo la fuente de verdad; un sync semi-automático lo convierte en recetas Markdown, detectando qué cambió de verdad para no revisar todo a mano cada vezThe Google Doc stays the source of truth; a semi-automated sync converts it into Markdown recipes, detecting what actually changed so not everything needs a manual re-check each time
  • Sub-recetas repetidas (masa sablée, crema pastelera) viven una sola vez como fragmentos compartidos e incluidos donde hacen falta, eliminando el problema de recetas duplicadas del Doc originalSub-recipes that repeat (sablé dough, pastry cream) live once as shared fragments included wherever needed, solving the duplicate-recipe problem from the original Doc
  • Datos rotos frenan la publicación: el export valida cada receta y nunca pisa el sitio en línea con contenido inconsistenteBroken data halts publishing: the export validates every recipe and never overwrites the live site with inconsistent content
